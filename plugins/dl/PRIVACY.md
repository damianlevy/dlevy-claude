# Política de privacidad de dl:loop

Última actualización: 3 de octubre de 2026.

## Alcance y editor

Esta política describe la edición de dl:loop para ChatGPT y Codex distribuida como un paquete de instrucciones y referencias, sin servidor MCP propio. Su editor es Damian Levy. El proyecto se mantiene en [damianlevy/dlevy-claude](https://github.com/damianlevy/dlevy-claude).

Esta política se limita a dl:loop. No describe otros plugins del repositorio ni sustituye las políticas de OpenAI, GitHub o de los servicios que el usuario decida conectar.

## Información utilizada durante una investigación

dl:loop orienta al asistente para trabajar con el objetivo, las restricciones, las fuentes y los documentos que el usuario aporta o autoriza a consultar. Esos insumos pueden contener información personal si el usuario la incluye. Se utilizan para encuadrar la investigación, comparar alternativas, documentar evidencia y preparar decisiones y entregables.

El paquete no incluye un servidor del editor, cuentas propias, formularios de registro, herramientas de telemetría, rastreadores ni un mecanismo para enviar automáticamente al editor las conversaciones, los archivos o los resultados. No solicita contraseñas, claves API ni datos de pago. Evitá incluir secretos o información personal que no sea necesaria para el trabajo.

## Quién procesa la información

La conversación y las herramientas se ejecutan en el entorno de ChatGPT o Codex elegido por el usuario. OpenAI y, cuando el usuario los autoriza, los proveedores de herramientas, buscadores o conectores pueden procesar los datos necesarios para la tarea conforme a sus propias condiciones, permisos y políticas.

Los agentes adicionales, cuando están disponibles, reciben el contexto que necesitan dentro del entorno de ejecución. El editor no obtiene acceso a ese contexto por el hecho de distribuir dl:loop. El paquete no incorpora un canal propio para vender, compartir con anunciantes o transferir al editor la información de una investigación.

## Archivos, almacenamiento y conservación

El trabajo puede producir informes, registros de evidencia, archivos de control y documentos HTML en la conversación o en el espacio de trabajo autorizado. Si un documento HTML guarda votos o notas, el asistente debe explicar el mecanismo utilizado; puede consistir en un archivo o en almacenamiento del navegador, según el entorno. El paquete no envía esos votos a un servidor del editor.

El editor no mantiene una base de datos de conversaciones o investigaciones de dl:loop, por lo que no establece un plazo propio de conservación para esos datos. La conservación en ChatGPT, Codex, conectores, archivos y copias de respaldo depende de la configuración del usuario y de las políticas de cada proveedor. Los entregables permanecen en esos entornos hasta que el usuario o el proveedor los eliminen conforme a sus controles de conservación.

## Soporte y consultas

El soporte del proyecto se gestiona mediante [GitHub Issues](https://github.com/damianlevy/dlevy-claude/issues). Si publicás una consulta, tu nombre de usuario y el contenido que incluyas podrán ser visibles para el editor, GitHub y otras personas, porque el repositorio es público. No incluyas conversaciones privadas, credenciales ni archivos sensibles en una consulta pública.

Las consultas sirven para responder preguntas y corregir problemas. Pueden permanecer publicadas como historial del proyecto hasta su eliminación. Las copias y registros que conserve GitHub se rigen por sus políticas. Para pedir una corrección o retirada de contenido del proyecto, abrí una consulta que identifique el contenido sin reproducir datos sensibles; también podés utilizar los controles y canales de privacidad de GitHub.

## Controles del usuario

Podés desinstalar o deshabilitar dl:loop, limitar las fuentes de una tarea, revocar permisos de herramientas y conectores, y administrar las conversaciones y los archivos desde el producto correspondiente. Desinstalar el paquete no elimina automáticamente las conversaciones ni los entregables ya creados. El editor no puede borrar por vos información almacenada en tu cuenta de OpenAI o en servicios ajenos.

## Cambios

Si una versión futura incorpora servicios propios o cambia estas prácticas, esta página se actualizará con la nueva fecha y el alcance correspondiente antes de distribuir esa versión.
